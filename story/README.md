# Story source

The Story view is built from one file: `manuscript.md`.

To refresh the manuscript, replace `manuscript.md` with the new version and
commit it. The site rebuilds on its own. Keep one `## ` heading per section,
with headings that match the chapter table (reference/ENTRY_PROTOCOL.md,
section 8); `supabase/load_chapters.py` checks them.

Current text: manuscript_final_with_appendix_2026-11-08.md, the canon for
story facts (contracted narration; Interludes I and VI and the Protocol
chapters 3, 6, 9, 12 and 15 uncontracted by design). It includes Appendix:
The Brief as its last section (story section 30). The text is final and is
not edited here.

`back-cover.md` is separate on purpose: it is the introduction on the Story
page.
